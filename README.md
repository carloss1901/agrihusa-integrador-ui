# Agrihusa Integrador UI

Interfaz de usuario del proyecto **Agrihusa Integrador**.

## Requisitos

- Node.js 18 o superior
- npm 9 o superior

## Instalación

```bash
npm install
```

## Ejecución en desarrollo

```bash
npm start
```

Si el proyecto usa otro script de desarrollo, también puedes probar:

```bash
npm run dev
```

## Compilación

```bash
npm run build
```

## Estructura básica

```text
.
|-- src/
|-- public/
|-- package.json
`-- README.md
```

## Notas

- Ajusta los scripts según la configuración real del proyecto.
- Agrega variables de entorno si el frontend consume APIs externas.
